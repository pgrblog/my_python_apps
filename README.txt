SCHOOL BUS MANAGER - ANDROID PROJECT STARTER

This package contains a mobile-friendly offline web app prototype for:
- 15 buses
- Bus registration/capacity/driver/helper/route
- Daily trips and odometer calculations
- Fuel records and automatic fuel cost
- Maintenance records
- Fines
- Overall fleet report

Data is stored locally in the browser/device.

To turn this into a signed APK, open www/index.html in a suitable Android WebView/Capacitor build environment or import the project into an Android app builder. This package itself is not a signed APK.
